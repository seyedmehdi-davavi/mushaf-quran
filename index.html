مصحف مدینه، روایت عثمان طه

نمایش آنلاین متن قرآن، تصویر صفحه و تلاوت آیه‌به‌آیه

فهرست، گزینه‌های شناخته‌شده/پیکربندی‌شده را نشان می‌دهد، نه تضمین پخش: پوشش «تحقیق» یا قاریان ایرانی در API ممکن است محدود باشد؛ دسترسی هر آیه هنگام درخواست سنجیده می‌شود و در صورت نبودن، پیام خطا می‌بینید.

در حال دریافت…

متن و صوت از API عمومی Al Quran Cloud دریافت می‌شود. تصاویر صفحه از EveryAyah/مخزن عمومی صفحات استفاده می‌کنند. برای پخش، اتصال اینترنت و اجازهٔ مرورگر لازم است؛ در صورت نبودن صوت، پیام خطا نمایش داده می‌شود.

منبع داده: alquran.cloud/v1 و everyayah.com | این فایل آفلاین نیست.
